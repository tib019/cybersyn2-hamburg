# Projektscope — Cybersyn2-Hamburg

## Problem
Moderne Städte wie Hamburg generieren riesige Mengen an Daten (Verkehr, Energie, Versorgung), die aber nicht kybernetisch gesteuert werden. Das historische Cybersyn-System Chiles (1971-73) zeigt das Potenzial adaptiver Echtzeit-Steuerung.

## Lösung
Cybersyn2-Hamburg ist ein Forschungs- und Konzeptprojekt, das ein modernes Cybersyn-ähnliches System für Hamburg konzipiert und prototypisch implementiert. Stufenweise Entwicklung von Datenerfassung bis kybernetischer Steuerung.

## In Scope
- Konzeptuelle Systemarchitektur (4 Stufen)
- Datenerfassung und -analyse (Hamburg-Daten)
- Simulationsschicht für Szenario-Tests
- Theoretische Grundlagen (Papiere, Dokumentation)
- Prototypische Implementierung der Kernstufen

## Out of Scope
- Produktionsbetrieb in Hamburg
- Integration mit realen Stadtinfrastrukturen
- Politische oder administrative Umsetzung

## Verzeichnisstruktur
```
cybersyn2-hamburg/
├── stufe1/   # Datenerfassung
├── stufe2/   # Analyse
├── stufe3/   # Simulation
├── stufe4/   # Steuerung
├── data/     # Datensätze
└── paper/    # Theorie-Dokumente
```

## Inspiration
Basiert auf dem Cybersyn-Projekt von Stafford Beer, durchgeführt 1971-1973 unter Salvador Allende in Chile — eines der ersten kybernetischen Wirtschaftssteuerungssysteme.
